# 洛天依 · Windows 界面样板

双击 AgentLuo.exe 启动。请保留同目录的 AgentLuo.pck、DLL 和 licenses 文件夹。

这是用于视觉确认的离线样板，Godot 4.7.1 / Windows x64。无需安装 Godot 或 Python。不连接服务器，不读取旧端凭据，消息在退出后清空。

- 左侧：真实 Live2D 模型；滚轮缩放，右键拖动，底部重置；左上切换表情。
- 中间分隔条：拖动调整角色与聊天比例。构图和比例会保存。
- 右上：切换聊天、空白、断网、加载失败和思考样例。
- 聊天：文本可选择复制；Enter 模拟发送，Shift+Enter 换行；发送失败样例在列表下方。
- 图片：选择文件或 Ctrl+V 粘贴图片，预览后显式发送；点击聊天中的图片可放大。
- 模拟口型：按钮切换口型与停止，没有声音。尚未接入真实语音。

请重点体验角色大小、45:55 分区、字体、气泡间距、输入区以及缩放/拖动手感。中文输入法组词、图片粘贴、多档 DPI 和集显性能尚需人工核验。

默认窗口 1200×800，最小 960×640。关闭即退出。用户设置保存在独立的 `%APPDATA%/AgentLuo-Godot`。

此样板不是最终安装程序；账户、真实聊天、流式音频等业务和完整功能对齐仍未完成。旧客户端保持可用。
