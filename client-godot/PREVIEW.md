# 洛天依 · Windows 开发客户端

双击 AgentLuo.exe 启动。请保留同目录的 AgentLuo.pck、DLL 和 licenses 文件夹。

Godot 4.7.1 / Windows x64，无需安装 Godot 或 Python。默认只显示账户窗口，预填原客户端服务器 `https://www-api.u3493359.nyat.app:11664`，可以自行修改；已保存的自定义地址优先。支持登录、注册、邀请码重置、自动登录和退出；自动登录凭据按 Windows 用户保护。不读取旧端凭据。

登录后可发送文字并接收回复，发送状态来自服务器确认。支持断线重连、原消息 ID 重试、思考状态和表情；无法确认送达时会明确提示。Enter 发送，Shift+Enter 换行；退出登录会关闭连接并清空当前会话。正式聊天尚未接入图片和历史。

收到的语音自动播放，支持流式 WAV/PCM、音量调节、停止当前语音及播放口型。后续回复按顺序呈现；坏音频会提示并保留文字。停止只影响当前回复，后续回复仍自动播放。音量会保存；当前尚不保存语音缓存，也没有历史回放。

聊天区点击“打开日志”，可查看 `%APPDATA%/AgentLuo-Godot/logs/client.jsonl`。`reply_received` 的 has_audio 表示该包是否有音频，`audio_received` 表示解码后的字节已接收，`audio_format/audio_decoded` 表示 WAV 格式识别和解码成功，`audio_playback_started/finished` 表示播放开始/结束，`audio_error` 的 code 表示具体失败原因。日志最多三份自动轮换，不记录正文、凭据或音频原文。

离线样板用 `AgentLuo.exe -- --preview` 进入，样板不连接服务器，演示消息在退出后清空。

- 左侧：真实 Live2D 模型；滚轮缩放，右键拖动，底部重置；左上切换表情。
- 中间分隔条：拖动调整角色与聊天比例。构图和比例会保存。
- 右上：切换聊天、空白、断网、加载失败和思考样例。
- 聊天：文本可选择复制；Enter 模拟发送，Shift+Enter 换行；发送失败样例在列表下方。
- 图片：选择文件或 Ctrl+V 粘贴图片，预览后显式发送；点击聊天中的图片可放大。
- 模拟口型：离线样板中的按钮没有声音；实际语音在登录后的正式聊天中播放。

请重点体验角色大小、45:55 分区、字体、气泡间距、输入区以及缩放/拖动手感。中文输入法组词、图片粘贴、多档 DPI 和集显性能尚需人工核验。

账户窗口默认 660×800，最小 480×640；登录后展开至 1200×800，最小 960×640，退出后重新收起。关闭即退出。用户设置保存在独立的 `%APPDATA%/AgentLuo-Godot`。

此开发版本不是最终安装程序，完整功能对齐仍未完成。文字及语音链路已通过本地模拟服务与合成音频验证，真实开发服务仍需联调。旧客户端保持可用。
