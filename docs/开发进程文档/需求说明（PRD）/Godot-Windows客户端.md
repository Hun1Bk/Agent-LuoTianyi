## 目标

交付可替换现有 Python 桌面端的 Windows 10/11 x64 客户端，面向普通集显、8 GB 内存电脑。保留当前用户功能，重新设计角色和聊天界面，最终提供当前用户范围的安装程序。开发期间保留旧客户端；验收后切换正式交付入口，旧发布包保留用于回退。

## 用户已确定的体验

1. 左侧角色、右侧聊天，初始比例 45:55，可调整并保存。
2. 安静的陪伴氛围，浅色低对比面板、深色文字、青蓝点缀；聊天排版参考新版 Windows QQ。
3. 复用现有背景、模型、头像；静态背景，不新增插画、背景音乐或持续粒子。
4. 角色保留眨眼、呼吸、表情、动作、视线、触摸和口型；支持滚轮缩放、右键拖动、保存及重置，左键仍用于触摸。
5. 普通窗口，原生标题栏，初始 1200×800，最小 960×640，关闭即退出。
6. 默认自动播放回复，可调音量及回放消息语音。
7. Enter 发送、Shift+Enter 换行；中文输入法组词时 Enter 不发送。支持文字选择复制、单张图片粘贴预览和显式发送。
8. 长文本换行；翻看历史时不被新消息强制拉到底部；历史分页保留阅读位置。
9. 先交付带真实模型和模拟消息的可运行样板，由用户确认后再展开账户、设置及动态页面。
10. 换端时重新登录和配置，历史及偏好从服务端恢复；不导入旧 token、API key、图片或语音缓存。

## 功能对齐验收矩阵

下表是需求范围，不表示已实现；完成事实只写入进度文档。

| 能力 | 基线行为和观察入口 |
| --- | --- |
| 账户 | 登录、注册、自动登录、邀请码重置、自定义服务器、退出；`/auth/*` |
| 文本 | `user_text`、`user_typing`、主动发言，发送状态、系统提示、连续输入 |
| 网络可靠性 | `user_auth`、`negative_ack_v1`、心跳、重连、原 ID 重试、终止拒绝、`DELIVERY_UNCERTAIN` |
| 图片 | 选择/取消、发送、预览、本地缓存及历史图片补下载 |
| 回复 | 按 UUID 聚合，保持文本/表情/音频顺序，识别隐藏及临时回复 |
| 角色 | 与旧端一致的表情命令、视线和触摸区域，在线语音期间抑制上报 |
| 媒体 | 流式 TTS、唱歌、口型、音量、终止及失败包、本地回放与在线音频优先 |
| 历史 | 分页、去重、阅读锚点；新端缓存可回放，旧端独有音频不承诺恢复 |
| 相处偏好 | 当前字段完整读取、编辑、保存，失败不丢输入 |
| 动态 | 列表、分页、发布、评论、未读及已读；失败保留输入，不误清红点 |
| 自备模型 | 服务端类型需求、LLM/VLM 配置、能力校验、参数透传、异步委托及失败回传 |
| 安装 | 无需 Godot/Python/.NET 的安装包，覆盖安装保留新端数据，卸载默认保留数据 |

## 非目标

首版不实现电话、移动端、桌宠、托盘、场景探索、昼夜系统、消息撤回/引用/全文搜索、自动更新或新角色。不改造服务端心智，不增加服务端路由或聊天事件。

## 失败行为与数据边界

- 重试复用消息 ID；瞬时输入不阻塞消息队列。明确鉴权失败停止同凭据重连。
- 服务端音频抢占本地回放。接收结束不等于实际播放结束。音频错误保留文字、结束状态且不保存部分失败流。
- 新端使用独立用户数据目录，服务器和账户隔离；退出取消任务并清除自动登录凭据，不混用其他账户缓存。
- API key 默认 DPAPI；保留旧端加密失败后由用户显式选择明文的行为，默认取消，不自动降级。
- 日志不记录密码、token、API key、完整委托提示词或 Base64 音频。

## 验收标准

1. 样板展示长短文本、图片、系统提示、发送各状态、思考、表情、语音状态、空列表及网络错误；真实导出包经用户确认视觉。
2. 自动化通过公开接口检查正常和失败行为；默认离线、无生产配置或计费模型。
3. Windows 10/11、100/125/150/200% DPI、中文及空格路径、中文输入法、窗口与双屏行为完成实际记录。
4. 基准集显机器 1200×800：平均至少 55 FPS，P95 帧时间不超过 33 ms；本地输入反馈小于 100 ms。
5. 连续音频及聊天 30 分钟无持续内存增长或无法结束的播放；受控网络口型偏差目标不超过 150 ms。
6. 1000 条历史仍可输入和滚动；最小化停止非必要绘制，不停止心跳或语音。
7. 发布前实际验证开发服务聊天、图片、TTS、唱歌、动态、自备模型和安装升级；离线测试不得冒充真机或真实服务验收。
